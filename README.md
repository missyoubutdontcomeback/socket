# Random Video Chat - คล้าย Ome TV

เว็บแอพพลิเคชั่น random video call สำหรับพบปะคนใหม่ทั่วโลก

## ฟีเจอร์

- 🌍 ตรวจจับประเทศอัตโนมัติ
- 👥 เลือกเพศของตัวเองและเพศที่ต้องการพบ
- 🎯 เลือกประเทศที่ต้องการพบ
- 🎥 Video call แบบ real-time ด้วย WebRTC
- ⚡ เชื่อมต่อเร็วด้วย Socket.IO
- ⏭️ ข้ามหาคู่สนทนาใหม่ได้ทันที

## การติดตั้ง

1. ติดตั้ง dependencies:
```bash
npm install
```

2. รัน Socket.IO server (Terminal 1):
```bash
npm run server
```

3. รัน Next.js development server (Terminal 2):
```bash
npm run dev
```

4. เปิดเบราว์เซอร์ที่ http://localhost:3000

## วิธีใช้งาน

1. เมื่อเปิดหน้าเว็บ ระบบจะตรวจจับประเทศของคุณอัตโนมัติ
2. เลือกเพศของคุณ (ถ้าเลือกชาย ระบบจะตั้งค่าให้หาหญิงอัตโนมัติ)
3. เลือกประเทศและเพศที่ต้องการพบ (หรือเลือก "ทั้งหมด")
4. กดปุ่ม "เริ่มค้นหา"
5. รอจนกว่าจะพบคู่สนทนา
6. เริ่มวิดีโอคอล!
7. กด "ถัดไป" เพื่อหาคู่สนทนาใหม่ หรือ "หยุด" เพื่อกลับไปหน้าตั้งค่า

## เทคโนโลยี

- **Next.js 14** - React Framework
- **Socket.IO** - Real-time communication
- **WebRTC** - Peer-to-peer video/audio
- **TypeScript** - Type safety
- **ipapi.co** - IP Geolocation

## หมายเหตุ

- ต้องให้สิทธิ์เข้าถึงกล้องและไมโครโฟน
- ใช้งานได้ดีที่สุดบน Chrome, Firefox, Safari
- ต้องมีอย่างน้อย 2 คนออนไลน์เพื่อทดสอบการจับคู่
